# System Logging Management

This project is a system logging management tool that allows you to manage your system logs.

## Installation

```bash
go get github.com/nlgolib/logger
```

## Highlights

### Logging

- [x] INFO logs
- [x] WARN logs
- [x] ERROR logs
- [x] DEBUG logs
- [x] Colored log level tag

### Log File Management
- [x] List Log Files
- [x] Read Log Files By Date
- [x] Read Log Files By Level
- [x] Delete Log File
- [x] Setup Log Folder Path
