# System Logging Management

This project is a system logging management tool that allows you to manage your system logs.

## Installation

```bash
go get github.com/nlgolib/logger
```

## Functionality Highlights

- [x] Log DEBUG, INFO, WARN, ERROR
- [x] Log Folder Management
- [x] List Log Files
- [x] Read Log File By Date
- [x] Read Log File By Level
- [x] Delete Log File
- [x] Setup Log Folder Path
